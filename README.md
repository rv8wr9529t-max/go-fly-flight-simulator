# go fly · 轻松起飞

一个无需安装依赖、可直接在现代浏览器中运行的单文件 3D 飞行小游戏。支持键盘与触屏操作，包含多种飞机、自由飞行、飞行教学、自动起飞与辅助降落等功能。

## 运行

下载或克隆仓库后，在现代桌面或移动浏览器中打开 `index.html` 即可开始。项目没有构建步骤，也不依赖外部 JavaScript 库；图形由浏览器 WebGL 渲染。

## 基本操作

| 操作 | 按键 |
| --- | --- |
| 飞行操纵 | 方向键或 W / A / S / D |
| 方向舵 | Q / E |
| 减速 / 刹车 | 按住 B |
| 射击练习气球 | 空格 |
| 切换视角 | V |
| 自动驾驶 | T |
| 自动摆正辅助 | L |
| 起落架 / 襟翼 | G / F |
| 暂停 / 帮助 | P / H |
| 返回跑道 | N |

游戏内也提供触屏摇杆、按钮和飞行教学。点击“一键起飞”可以自动加速并爬升；“自动降落”可启动辅助降落。
